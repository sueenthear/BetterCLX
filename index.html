Better CLX

让一梦江湖多开与连招管理更清晰。

统一管理游戏启动、脚本启动、窗口绑定和连招动作。使用 Win32 API 将键盘与鼠标事件发送到指定游戏窗口。

前往最新 Release查看界面

为重复操作而设计

启动、绑定、编辑和执行都围绕单一目标窗口展开，减少误操作和配置分散。

启动管理

支持游戏路径手动配置与 BFS 查找，多个脚本分别保存启动路径和更新网址。

单窗口绑定

窗口检测、登录状态和 HWND 绑定集中管理；单击聚焦，双击绑定，并保留缓冲时间。

连招编辑

支持组级多触发器、切换/按住模式、键盘动作、延时和鼠标滚动，动作按列表顺序执行。

界面预览

启动、绑定和连招编辑保持一致的工作区布局，方便快速扫描状态与修改动作。
